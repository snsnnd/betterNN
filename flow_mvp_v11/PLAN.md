# 第十一轮：Replay 比例 × {all, freeze_W} × 3 任务顺序

## 问题

第十轮已建立每个任务单独可学（~99.8%）的 A'B'C'D' benchmark，顺序 CL 基线最终平均 80.80%、遗忘 22.10 个百分点。本轮直接回答：

> **底层河床保持稳定（freeze W），只让调制器快速学习，同时用少量旧经验（replay）防止控制策略漂移，能否同时获得可塑性与稳定性？**

## 固定协议

- N=256 dense，A'B'C'D' 任务，65 轮/阶段（第十轮验证选出的 E95）。
- 每步总样本固定 128，4 步/轮：`128 = cur + replay`，replay 只替换当前数据，不额外加量。
- replay 比例 r ∈ {0, 6.25%, 12.5%, 25%, 50%}（每步回放 0/8/16/32/64 个旧任务样本）。
- 回放缓冲：每个已学任务固定保存 32 个训练样本；从第二步开始，从所有旧任务样本中均匀有放回采样。
- 当前任务的批顺序使用独立随机数生成器，保证同一 (order, seed) 下所有比例的当前数据完全一致，唯一差别是注入的 replay 样本。
- 组：`all`（全部可训练）与 `freeze_W`（先全参数学习顺序中的第一个任务，之后冻结 W，只训练控制器与读出）。
- 顺序：`o0`=[A',B',C',D']，`o1`=[D',C',B',A']，`o2`=[B',D',A',C']。
- 5 个种子 11/22/33/44/55，共 2×5×3×5=150 条流。

## 记录指标

- 任务×阶段矩阵（按任务 ID 排列，跨顺序可比）
- acquisition、final_mean、forgetting、BWT、epochs_to_90
- 冻结检查：freeze_W 组的 W 在第二阶段后逐位不变
- 基线核对：o0 + all + r=0 应与第十轮 CL 基线逐位一致

## 判定关注

- replay 比例对 final/forgetting/acquisition 的曲线
- freeze_W 与 all 在各比例下的配对差值
- 是否存在“高保留且不牺牲新任务获取”的 Pareto 区域，尤其是 freeze_W × 中低比例 replay
- 顺序鲁棒性：结论是否在 3 个顺序上一致

## 边界

- replay 为等样本预算替换，当前任务暴露量随比例下降（r=50% 时每轮只看 256 个当前样本）。
- 只有 5 种子、3 个顺序、单一规模与任务集；结论限于本协议。
- 回放样本为固定 32/任务，未扫描缓冲大小。
