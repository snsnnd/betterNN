## 这轮纠正的三处推理

1. 上一轮约86%是15%标记翻转条件下已知生成分布的Bayes参考，不是模型实测成绩。
2. 旧seed同时改变数据、mask、权重，观察到seed依赖不能直接证明拓扑因果作用。本轮先描述，再固定数据和其他权重改变mask。
3. 延迟规则任务可以由GRU或状态/读出隐式计算解决，不能预先定义为只有显式Route能解决。

## 旧模型路由指标

64节点划成4组，g有4个值，各值作用于一组源节点的所有出边。指标按组出边数加权。报告三个阈值下的“门值超过阈值的边比例”、软门均值、Bernoulli熵代理、相邻时刻变化、同信号不同任务的门距离。

sigmoid软门通常不为零，代码仍执行稠密计算。阈值比例不是真实active FLOPs或省带宽；熵代理衡量g接近0.5与否，不是门随时间变化的熵。常数门0.5也有高熵代理。

global/task静态替换由训练集估计均值，测试时直接替换；这属于干预，不是重新训练。另有独立静态门训练组。任务间模式不同而时间变化小，应称“任务条件配置”，不可直接称为持续动态路由。

## 控制拓扑

数据seed42000、训练批次seed5000全部固定。权重seed101/202各配5个mask seed，B/C、控制器、读出和完整候选W在同一权重seed内完全相同。mask变化后重新归一化有效W谱范数到0.9。

每组合训练no_route（I+H）及dynamic（完整三门），共20次；weight seed101另训练5个static门组。static保留同一MLP但输入恒零，所以输出常数。登记参数个数相同不代表有效自由度相同，首层权重梯度为零。W始终冻结。

图指标：去自环的有向可达路径、可达比例、强连通分量；去自环无向投影聚类；含自环W的谱半径、谱范数、有效秩、边数。只探索ER密度约20%的小范围，n=5相关系数不能证明显著关系或外推最优拓扑。

## 可学习Salience

同旧数字任务，但给每个事件一个4类key。真正相关的事件由key==query决定，所有组看payload/key/query/time，因此去掉valid bit后仍可辨识。

perfect使用解析匹配结果作为额外控制信号；noisy将解析结果15%翻转；learned用8→16→1网络从key/query学习连续信号，仅使用最终任务损失；none固定该接口为0，但原始key仍进入底层，检验是否需要显式salience接口；GRU直接读相同原始字段。

learned从未收到相关性辅助标签，也看不到payload数值或最终答案。所有Flow的原始key经固定E进入底层，这是公平可观测输入，但也允许底层自己处理key，所以若成功，不能自动把全部收益归给salience分支。

记录AUC及相关/无关事件上的平均s。输出方向没有监督，AUC接近0也可能表示反向编码相关性；必须结合均值和任务性能解释。若AUC约0.5，仅有任务得分不能宣称学会了重要性。

noisy组同时看原始key，可学着纠正错误；这个任务不能套用上一轮没有key时约86%的上限。

## 延迟规则

先输入A/B两个高斯数，随后收到R=0/1，最后输出两个二分类值：R0为(signA,signB)，R1交换。两个输出全部正确才算主准确率。

规则出现前输入中没有R。ID规则位于6..9、总长12；更早规则2..5；更晚规则18..21总长24；长保持为规则仍6..9但输出到24。还报告A/B异号子集、逐位准确率、保持A/B和时间不变只翻转R后的双方都正确率。

对照I+H、完整动态Route、静态Route、完整模型慢速W、10单元GRU。候选状态和线性读出均可参与计算，没有物理分隔的X/Y模块端口，所以不能把任务正确自动解释成信息沿指定子图流动。

## 验证与限制

3072训练、768验证、每测试4096；除拓扑控制使用固定数据外，新任务3种子11/22/33。只用ID验证选checkpoint，100轮、batch256、Adam0.003，slowW0.00015，未按测试成绩改超参数。

三个研究的训练时段有重叠，不用记录的秒数作速度排名。固定B/C等不变，模型仍需通过固定网络反传。少量种子、固定超参数、简单合成任务，不能据此宣称通用智能或新架构全面优势。

verify.py核验：同weight seed的拓扑组除mask/W外初始参数完全相同；谱范数；内容匹配与标签；规则无提前泄漏；重载55个新检查点、复算180项主指标及额外诊断、冻结张量一致。

## 探索性分支：16个源—目标组门

旧4门满足W_eff[i,j]=g[group(i)]*W[i,j]，同一源到不同目标的相对权重不变，因此不能直接独立选择分支。观察原延迟任务失败后，追加block_dynamic/block_static（共6次），把门扩为4×4，允许每个源组对各目标组独立控制。

这个追加不是最初预设。训练/验证沿用延迟任务，新增测试seed加700000；原5组延迟模型也在同一新测试重新评估。模型增加了门参数，不能把任何差异纯粹归于路由形式。该探索分支不改变或替换原失败结果。
