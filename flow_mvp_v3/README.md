承接另一对话《神经元模型比较》2026-09-25约12:58的建议。本轮落实三门完整消融、底层训练方式对照和有效标记可靠性；组合任务、硬带宽预算与扩展规模留作后续阶段。完整结果见REPORT.md，预先确定的设计见EXPERIMENT_PLAN.md。

## 快速运行

Python 3.10+，CPU，无外部数据。

```bash
pip install -r requirements.txt
python predict.py
python verify.py
```

重训全部75组：

```bash
python experiment.py --epochs 100 --seeds 11 22 33 44 55 --out results_reproduced
python verify.py --out results_reproduced
```

只复现简化输入门＋保持门：

```bash
python experiment.py --variants g101 --seeds 11 --out quick_run
python predict.py --checkpoint quick_run/g101_seed11.pt
```

## 命名

`gIRH`中，I是输入门、R是内部通路门、H是状态保持门。1代表启用并学习，0代表关闭这个调制机制。I/R关闭时通路全开，H关闭时更新系数固定0.2；并非把信息清零。

## 数据与评估

任务与第二轮保持一致：四路12步独立高斯信号，q指定一路，从前6步随机选择2个有效时刻，最终判断指定通道有效值之和的正负。3072训练/768验证/4096每项测试，100轮、batch256、Adam0.003；slowW为0.00015。5个种子11/22/33/44/55。只按相应提示分布验证准确率选checkpoint；不按OOD结果选。

五种主测试：同分布id12、有效位置移到后六步shift12、整段随机位置random12、干扰延长到24步delay24、无效信号标准差3倍noise12。每组主测试的标记可靠性与该组训练模式一致；因此不能把noisy组的id12与clean组当作完全同条件对照。

额外三项ID测试均基于相同信号、任务、真实标记和标签：clean_id（正确标记）、noisy_id（15%独立翻转）、none_id（标记全0）。不同模型使用相同噪声样本。noisy训练每例固定噪声实现，各split独立；不逐轮重新采样噪声。

在表中比较提示可靠性时，按clean_id/noisy_id/none_id列比较，区分训练与测试分布，避免混淆适应能力和压力测试。

## 无标记的参考上限

无标记时，模型仍知道q和时间，但不知道随机选中的两步。已知其均匀选自前六步，可枚举15个可能位置对。令p为15种情况中标签为1的比例，则最优预测为多数标签，对该输入的最优期望正确率为max(p,1-p)。在独立测试信号上对它取均值，得到生成分布下条件最优准确率的蒙特卡洛估计，非严格有限样本硬上界。

同时报告多数规则与本次实际标签的经验准确率。后者可能因标签采样而略高或低于期望估计。此参考仅用于ID、无标记、噪声标准差1且有效位置前六步的任务，不能直接套到15%翻转、shift或强干扰。

这不是模型“凭空找到了重要性”；它只是利用已知位置先验给出最有可能的答案。去掉随机标记后，任务本身不再完全可辨识。

15%翻转提示还补充了同一生成分布的Bayes参考：枚举15个位置对，按该候选生成观测提示的概率加权，再预测多数后验标签。其结果只用于分析，不参与训练与选模。

## 实现与核验

v2_reference.py是第二轮源码副本，作为初始化、数据生成和GRU实现的固定依赖，不需要另下载第二轮。experiment.py扩展独立三门开关；verify.py检查g111初始状态及输出与第二轮完全一致，检查每组梯度、冻结参数和标签规则，并重载全部模型复算。

每10轮记录训练子集的分通道准确率、有效/无效注入强度和更新系数。轨迹用于描述何时出现关闭现象，不自动构成因果解释。测试通道统计使用前1024例，所以与第二轮全4096例的分通道诊断不完全相同。诊断不会影响选模。

H启用时更新系数初始化0.1，不启用时固定0.2，所以H的整体作用含初始时间尺度差异。第二轮已有固定0.1参考，但本轮不把所有H收益归于自适应能力。五种子标准差也不是置信区间，基线未穷尽调参。
