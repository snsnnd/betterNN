# 第三轮预先确定的计划

依据另一对话《神经元模型比较》2026-09-25约12:58的建议：三门完整消融、降低有效标记依赖、组合任务、带宽曲线，最后扩展规模。本轮执行前两项和底层训练方式对照；组合任务、真实通信预算及扩展规模属于后续阶段，未声称已执行。

问题：下层是否必要？关闭输入门的失败是否随结构变化？冻结/慢速/联合W哪个更合适？标记不可靠的下降是单纯分布变化还是信息不足？

保持第二轮生成规则、样本规模和学习率。固定5个种子11/22/33/44/55，各组同数据和批次顺序。训练3072、验证768、每测试4096，100轮，batch256，CPU单线程，Adam0.003，slowW学习率0.00015，jointW学习率0.003。固定稀疏拓扑，B/C始终冻结；joint仅指W与控制器和读出联合训练，并不训练编码B/C或拓扑。

八组门消融：Input、Route、Hold的完整2×2×2组合，分别从头训练。I关闭时p=1；R关闭时g=1；H关闭时a=0.2；H开启时a=0.2*sigmoid(Linear(q,time,mark))，初值0.1。H主效应包含初始化/时间尺度差异，第二轮有固定0.1对照，本轮不把H收益全部归因于自适应。

额外对照：完整三门slowW、完整三门jointW、小GRU（8单元）。所有Flow初始W/B/C/控制器/读出共享种子；消融不改变初始化随机数消耗。

提示可靠性：每个已训练模型测试干净、15%独立翻转、完全移除标记；标签始终由真实标记定义。再给预先选定的简化I+H模型与小GRU各增加“训练验证测试均15%翻转”和“均无标记”的重训组。每样本固定噪声实现，不逐轮刷新，验证/测试噪声独立。只按相应提示分布验证集选checkpoint；不按压力测试选模型。

总计15组×5种子＝75次训练。每个模型评估5种与训练提示可靠性匹配的分布，以及3种ID提示测试，共600个指标（包含部分重复的clean_id/id12等，不能视为600个独立实验）。

无标记任务的有效位置本来就是随机选的，移除标记后不能唯一确定答案。额外枚举前6步的15对位置，计算已知生成分布下的Bayes多数预测和条件最优期望准确率，避免把信息缺失误称为神经网络能力不足。

每10轮记录训练子集各任务通道的有效/无效注入强度、更新系数、准确率。检查点仅由验证集选择；测试后的通道诊断不参与优化。未引入防关闭正则或门控下限，以免改变消融解释。

不宣称：自主发现无标记重要性、真实带宽或稀疏加速、架构全面领先。先验证机制和提示信息条件，再设计组合任务。三门包含已有门控思想，不将组合本身视为创新证明。
