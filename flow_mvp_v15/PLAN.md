# 第十五轮：Flow-v2 正式基线（结构删除 Write）

## 背景

第 14 轮判定 Write 门没有可测贡献。本轮按计划把它从代码结构上彻底删除，建立新的正式基线：

```text
cand = tanh(rec + x_t B)
```

不再有 `p = Write(meta)`、也不再注册 Write 参数。

## 设计

- 模型：Flow-v2 = W + Route + Hold + Readout（`flow_mvp_v15/experiment.py`）。
  为保持与 v11/v14 相同的随机初始化流（W/B/mask/hold/route/heads 的初始化不因删除 Write 而改变），构造时用一个**不注册的临时小网络**消耗掉与旧 Write 相同的 RNG，然后丢弃。
- 条件：r ∈ {0, 6.25%, 12.5%} × 顺序 {o0, o1, o2} × 5 种子 = 45 条流；65 轮/阶段、每步 128 样本、缓冲 32 样本/任务，与第 11/12 轮完全一致。
- 回归核对：o0 + r∈{0,12.5%} 应与第十四轮 `const1` 路径**逐位一致**（p≡1 与常数注入数学等价）。

## 判定

- 若复现 r=0 ≈ 77%、r=6.25% ≈ 97%、r=12.5% ≈ 99%，则正式冻结 `Flow-v2 = W + Route + Hold + Readout`，后续实验都以此为准。
- 同时报告与第 11/12 轮（含死模块 Write 的旧 Flow）的差值，量化删除的影响。

## 边界

- RNG 对齐只保证同种子下初始化相同，不改变任务与协议。
- 只测 3 个比例、3 个顺序、5 种子；结论限于 A'B'C'D' 与 N=256。
