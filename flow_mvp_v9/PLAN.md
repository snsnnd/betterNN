# 第九轮计划：持续学习遗忘定位

承接第八轮判定（H2/H0：Top-K 收益主要来自稀疏隔离）。本轮不再复杂化选择机制，直接定位 A→B→C→D 顺序学习中**遗忘发生在哪一部分参数**，并给出固定预算 replay 基线。

## 协议

- 基础模型：N=256 dense，与第八轮 dense 完全相同的任务、数据、超参数（30 轮/任务、batch 128、5 步 BPTT、无测试集选模型）。
- 先**全参数**学习任务 A 作为共同起点（每种子一个预训练检查点，所有组共享）。
- 再依次学习 B、C、D，每组对参数施加不同的保护；每阶段结束评估全部四个任务。
- 5 个种子 11/22/33/44/55。

## 参数组与实验组

| 参数组 | 包含 |
|---|---|
| W | 底层循环矩阵 |
| ctrl | write、hold、route |
| readout | headX、headY |

| 组 | 可训练参数 | 目的 |
|---|---|---|
| all | W+ctrl+readout | 全量更新对照 |
| freeze_W | ctrl+readout | 底层保护 |
| freeze_ctrl | W+readout | 控制器保护 |
| freeze_readout | W+ctrl | 读出保护 |
| ctrl_only | ctrl | 只更新控制器 |
| readout_only | readout | 只更新读出 |
| replay | W+ctrl+readout | 固定预算 + 旧任务小样本回放 |

replay 采用**等样本预算替换**：每一步仍为 128 个样本，其中 96 个来自当前任务、32 个来自旧任务缓冲；每个已学任务固定保留 32 个训练样本。相比非 replay 组，当前任务每轮暴露量减少 25%，这是固定预算回放的固有代价，报告中必须说明。

## 记录指标

- 任务×阶段矩阵（4×4，第 0 行为预训练 A 后）
- acquisition_A、acquisition_BCD（B/C/D 刚学完平均）
- final_mean、forgetting（A/B/C 的学后最好成绩减最终）、BWT
- epochs_to_90（每阶段验证达到 90% 的轮数）
- 各组参数位移：‖ΔW‖、‖Δctrl‖、‖Δreadout‖（预训练起点→最终）
- 独立适应对照：从同一预训练起点单独学习 B/C/D（全参数），判断“学不会”与“遗忘”的区别

## 预先约定的判定

- 若某保护组 forgetting 明显低于 all 且 acquisition_BCD 不明显受损 → 该参数组是主要遗忘来源。
- 若某组 acquisition_BCD 接近其独立适应对照 → 学习能力未受损；若远低于对照 → 保护妨碍了新任务学习。
- replay 与保护组并列为候选方案；只有同时报告“保住旧任务”和“学会新任务”两面的组才视为有效。

## 边界

- 只测一个任务顺序、5 个种子、单一合成任务与固定超参数；保护组与 all 的总可训练自由度不同，不能把差异全部归因于某一参数组。
- 预训练 A 使用全部参数，所有组起点相同；A 的成绩不作为遗忘比较的分母以外的用途。
- 冻结参数仍参与前向与反向传播；Top-K/门控未启用，本轮不涉及稀疏隔离。
