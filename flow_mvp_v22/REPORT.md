# 第二十二轮：Long-range Credit Attribution（长程信用归因）

协议：8 arms 的 2³ 因子（{W, Route, Hold} 哪些拿 Full 20 步信用；B 恒可训练恒 Full）；每个 step 同快照双通道（截断 period=5 / 完整 20 步）逐组拼装梯度；双 optimizer、分别 clip，其余与 V21 hybrid 一致；A'B'C'D'、10 seeds、r=12.5% 跑 o0/o1/o2、r=0 只跑 o0。

## 0. 结论摘要

1. **预注册 2³ 归因在匹配口径下是零结果**：G = F(B) − F(All) = 0.17pp；ME_W/R/H = -0.14/+0.05/+0.36pp（同向 5/10、4/10、5/10）——没有任何子集的长程信用能稳定改变 r=12.5% 遗忘（H1/H3/H4/H5 未通过）。
2. **V21 的 hybrid→Full gap 大部分是聚合错配**：原口径 6.63pp（3 顺序）vs 1.83pp（仅 o0）表面差 4.80pp；匹配 5 seeds/3 顺序后 B 6.63 vs All 5.53 = **1.11pp**；10 seeds/3 顺序 = **0.17pp**，且分顺序符号翻转（o2 Full 反而更差 −1.94pp）。
3. **r=0 负控干净**：所有 arm ≈23–27pp，|ME|≤0.4pp——信用窗口只在 replay 下才有任何（微弱的）作用。
4. **信用审计**：训练后 W 的 5 步梯度方向与 20 步严重失配（cos≈0.33、模长≈6–10%），hold≈0.5、route≈0.75–0.85；但"窗口损失"并不转化为遗忘差异——梯度几何失配不是功能重要性的可靠代理。
5. **含义**：现有证据支持"**B 的完整信用是必要杠杆（V21），core 的 5 步窗口在这些任务/协议下足够**"。Flow-v3 的 local/online 长程信用不应以 core 为首要目标，除非先在能暴露窗口缺陷的协议（更长序列/多事件/部分可观测）上复现出窗口效应。

## 1. 协议核验（Phase 0）

- `B` 臂 vs V21A hybrid：max|Δ matrix| = 0.000e+00（5 条配对），应为 0 → 通过
- `All` 臂 vs V21D：max|Δ matrix| = 3.809e-02（5 条配对），门槛 0.02 → 未通过
  - 原因：V21D 用单 optimizer+联合 clip，V22 用双 optimizer+分别 clip；首 batch 上两条通道梯度逐位相同，但训练中 clip 会生效（实测 max pre-clip norm ≈1.9–2.5），联合/分别 clip 的缩放比差 O(‖g_B‖²/‖g_core‖²)≈1e-3–1e-2，在 1040 步混沌轨迹上放大到矩阵差 0.04；
    遗忘层面 o0/5 seeds 均值 1.95pp vs V21D 1.83pp（Δ+0.12pp）——协议在结论层面等价。

### V21 hybrid→Full gap 的重审（关键）

- V21 原口径：hybrid 3 顺序（5 seeds）6.63pp vs Full 仅 o0（5 seeds）1.83pp → 表面 gap 4.80pp
- 匹配口径（同 5 seeds，3 顺序）：B 6.63pp vs All 5.53pp → gap **1.11pp**
- 10 seeds 3 顺序：B 5.40pp vs All 5.22pp → gap **0.17pp**
- All 仅 o0（5 seeds）：V22 1.95pp vs V21D 1.83pp（Δ+0.12pp），协议在遗忘层面一致
- 分顺序 B−All（10 seeds，正 = Full 更好）：o0 +1.08pp (5/10)、o1 +1.39pp (6/10)、o2 -1.94pp (4/10)

结论：V21 的表面 gap 主要来自 **3 顺序 hybrid 对 o0-only Full 的聚合错配**；匹配口径下 gap 从 4.80pp 缩到 ~1.1pp（5 seeds）/0.17pp（10 seeds），且分顺序符号翻转。

## 4. 预注册判定

- **H0a**：B 臂逐位回归 V21A hybrid（max|Δ|=0.0e+00） → **通过**
- **H0b**：All 臂对 V21D max|Δ|≤0.02（实测 matrix 3.809e-02；遗忘均值 o0/5seeds 1.95 vs 1.83） → 未通过
- **H0c**：audit min core cos5=0.309<0.9 → **通过**
- **H1**：max(ME_R,ME_H)=+0.36pp ≥1.5 且 ≥ME_W+1.0；最优因子 hold 同向 5/10 → 未通过
- **H2**：closure(B+W)=nan≤0.25 或 ME_W=-0.14pp≤1.0（G≈0，closure 不可解释；以 ME_W 为准） → **通过**
- **H3**：closure(B+R+H)=nan≥0.5（G≈0，不可评估） → 未通过
- **H4**：max(LOO_R,LOO_H)=+0.09pp ≥0.5G（G≈0，不可评估） → 未通过
- **H5**：所有 ≤2 因子臂 closure<0.5（B+R+H nan、B+W+R nan、B+W+H nan）（G≈0，不可评估） → 未通过
- **Hneg**：r=0 所有 |ME_X|≤1.0pp：W=-0.32、route=+0.14、hold=-0.38 → **通过**

### 解释（exploratory）

- credit audit 显示 core 的 5 步梯度确实"看不远"（W 训练后 cos≈0.33、模长≈6–10%），但功能实验说明 A'B'C'D' 不依赖 core 的早期时间信用：B 可以把长程信息写进状态，core 只需在尾部窗口内完成读出；因此窗口失配不构成遗忘瓶颈。
- o0 是唯一有弱信号的顺序（hold ME +0.79pp、9/10；B−All +1.08pp），o1 同向但不显著（+1.39、6/10），o2 反转（−1.94、4/10）。V21D 只在 o0 测过 Full，不能外推到 3 顺序。
- o0 上可见 B×core 的超加性（fixed-overlap+core full 4.66、hybrid 5.01、两者同时 1.95），即 B 的 Full credit 与 core 的 Full credit 互为部分替代；但该交互同样只在 o0 成立。
- 预注册的"Route/Hold 是主要载体"（源自 v13 的策略定位）在匹配协议下不成立：Route 主效应 +0.05pp、Hold +0.36pp、W −0.14pp，均低于噪声量级。

## 6. 边界

- 归因对象仅 {W, Route, Hold}；B/readout 恒 Full（readout 两条通道梯度逐位相同）。
- 混合信用 = 逐参数窗口选择，非新优化器；B 恒 Full 以与 V21 的解耦问题解耦。
- r=0 为负控；主判定在 r=12.5%、3 顺序聚合、10 seeds。
- 主效应/closure/LOO 的 seed 配对使用同一 seed 的全部 arm；t 仅作描述性参考，不作显著性结论。
- 负控 r=0 只纳入 o0（预注册口径）；误跑产生的 45 条 r=0/o1、o2 流移至 `results/extra_r0_orders/`，不进入任何判定。
