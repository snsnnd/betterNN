## 5. 预注册判定

- T=80 burst5−single：ΔAcc500=+2.4pp（4/5 同向）、ΔAUC=+1.4pp（3/5 ≥+1pp）、E95 有利 4/5 → **weak（2–3pp，不判 H-cap）**
- T=80 decay-slow−single：ΔAcc500=+1.9pp（4/5 同向）、ΔAUC=+1.4pp（3/5 ≥+1pp）、E95 有利 4/5 → **H-opt**
- T=160 burst5−single：ΔAcc500=+14.6pp（5/5 同向）、ΔAUC=+19.3pp（5/5 ≥+1pp）、E95 有利 5/5 → **H-cap**
- T=160 decay-slow−single：ΔAcc500=+14.7pp（5/5 同向）、ΔAUC=+19.2pp（5/5 ≥+1pp）、E95 有利 5/5 → **H-cap**

结论映射：T=160 若 H-cap → temporal kernel 改变最终能力，支持多时间尺度状态；仅 H-opt/H-null → delayed benchmark 上主要是收敛速度或无效，delayed 线降级、主证据收缩到 Chain-select（V24 500ep 已验证）；只有 H-cap 才实现 C/D（adaptive bank）与 continuous λ。

## 6. 边界

- Acc451-500 与 E90/95/98/AUC 均为 val 指标，不用测试集选模；E 未达到记 None。
- 500 epochs 是共同预算上限，不构成“充分收敛”证明。
- 2–3pp 的稳定差记为 weak，不判 H-cap。
