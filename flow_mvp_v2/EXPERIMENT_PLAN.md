# 第二轮预先确定的实验设计

2026-09-25，运行前写定；不根据测试集成绩改超参数。

目的：拆分信息选择与信息保持，排除第一轮“固定前四步有效”的时间规则。

数据：四路独立高斯信号；任务 q 指定一路；每个样本恰有两个随机有效时刻。标签为指定通道两个有效值之和的正负。有效标记是外部可观察输入，不由标签推导。模型在末尾回答。训练 T=12，有效时刻从前六步中随机选择两个。

输入公平性：所有模型获得信号、任务、时间和标记。clock_flow 的上层不直接访问标记，但其底层仍看到标记。因此它不是完全不知标记的模型，而是限制控制接口的消融。

对照：冻结储备池仅读出；只看任务与时钟的上层＋下层；看标记的上层＋读出；看标记的上下层＋读出；同模型增加可学习状态保持门；慢速 W 微调；严格仅训练控制器；8单元GRU；64单元GRU。

所有 Flow 共64节点、四块、20%稀疏拓扑、相同种子初始化。基础更新系数固定0.2；保持门组将其替换成 0.2*sigmoid(linear([q,time,mark]))，只新增7个可训练参数。它不直接硬编码“有标记就更新”，参数需从训练集学习。保持门的初始系数为0.1，故与原模型的差异包含自适应能力和初始化差异；不能把所有收益自动归给自适应保持。若产生明显收益，需固定0.1对照进一步拆解。

三种子11/22/33；训练3072、验证768、每种测试4096；100 epoch、batch256、Adam学习率0.003，W微调0.00015；仅ID验证集选检查点。相同种子、各模型批次顺序相同。测试集独立生成，五种条件独立取样，分布迁移差值不是逐样本配对结果。

测试：
- id12：与训练分布相同，有效时刻随机在前六步。
- shift12：有效时刻改为训练从未出现的后六步。
- random12：有效时刻随机分布在整段12步。
- delay24：有效时刻仍在前六步，后续干扰延长，总长度24。
- noise12：与ID位置相同，所有无效时刻的信号标准差由1变3。

干预：标记全部清零；主模型上层全开/下层全开；保持门组强制回到固定0.2。在ID和延迟条件评估。标记清零及门控强制改变属于分布外干预，不是重新训练对照。

有效信号可由已知规则直接求和得到100%正确率，作为数据/标签检查的算法上界，不参与神经网络排名。本轮没有验证模型能从无标记原始信号中自主发现重要性。

不做：硬top-k带宽、量化、脉冲相位、真实稀疏加速；不宣称语言智能或新架构。报告所有预设组，包括失败结果。第一轮与第二轮任务、数据量和输入改变，不能直接比较准确率涨跌。
