# 大网＋双层调制器：最小可复现实验

本项目将聊天中的设想缩小为可测量的问题：**在底层随机网络固定时，能否通过学习信息注入与通路调制解决带干扰的时序任务？**

这是合成任务上的概念验证，不是语言模型，不是智能涌现证明，也不是与大模型的性能比较。完整实测结果见 `REPORT.md`。

## 快速运行

建议 Python 3.10 或以上，CPU 即可，无需数据下载或 GPU。

```bash
pip install -r requirements.txt
python predict.py
python experiment.py --epochs 100 --seeds 11 22 33 --out results_reproduced
```

`predict.py` 默认加载已提供的真实训练权重。`experiment.py` 从零训练八种对照，每种三个随机种子，生成检查点、指标和训练记录。若只想跑核心模型：

```bash
python experiment.py --variants modulated --epochs 100 --seeds 11 --out quick_run
python predict.py --checkpoint quick_run/modulated_seed11.pt
```

重新绘制原始三种子完整实验图：`python make_plot.py`。该绘图脚本针对本次默认八模型、三种子结果。

## 聊天概念与代码对应

| 聊天里的概念 | 最小实现 |
|---|---|
| 一张大网 | 64 个状态节点，20% 随机有向连接，四个节点块 |
| 水流 | 有正负值的连续状态向量；不是遵守流体守恒的物理水流 |
| 编码器 | 固定随机线性投影 B；输入已是四维数值信号 |
| 下层调制器 | 小 MLP，根据任务指令和四块状态均值产生四个出边门控 |
| 上层控制器 | 小 MLP，根据任务指令与相对时间，输出四路连续注入强度 |
| 解码器 | 一个线性二分类输出层，不能直接访问原始输入或任务指令 |
| 底层慢速适应 | 固定稀疏拓扑下，以控制器 1/20 的学习率更新 W |

此次上层只实现**注入位置/通道和随时间变化的强度**。频率、次数、相位、停止时间的离散决策未实现。序列固定 8 步；连续软门控不等于真实减少传输次数。没有把“所有通道平均变暗”冒充带宽下降。

## 数学形式

令任务指令 q 为四维 one-hot，输入 z_t 为四路信号，状态 h_t 为64维；代码使用行向量：

```
p_t = sigmoid(Upper([q, t/(T-1)]))                # 四路注入强度
s_t = mean_pool_by_block(h_t)                    # 四块状态摘要
g_t = sigmoid(Lower([q, s_t]))                   # 四组出边通畅度
h_(t+1) = 0.8*h_t + 0.2*tanh((h_t * expand(g_t)) @ W
                            + (z_t * p_t) @ B + q @ C)
logit = h_T @ w_out + b_out
loss = binary_cross_entropy_with_logits(logit, y)
```

等价的有效循环矩阵为 `diag(expand(g_t)) @ W`，即按源节点组调制边，非逐边独立控制。C 是固定任务投影，各储备池对照都保留它，避免无调制器模型完全不知道任务。上层不能看信号数值，下层不能看原始信号或标签；所有预测必须经过网络状态。

W 初始化谱范数为 0.9，B、C 随机固定。由于 tanh 有界、初态为零且采用凸组合，每个状态分量保持在 [-1,1]。**这不构成全局收敛或智能涌现证明**：状态依赖门控带来的导数项不能忽略，微调后 W 的范数也不保证继续为 0.9。

## 验证任务

每个样本有四路独立高斯信号，每路 8 个时刻。任务指令随机指定一路；标签是这一路**前四步之和是否大于零**。后四步继续输入独立干扰，要求模型在最后一步作答。标签没有额外注入模型，任务指令不包含答案。

每个种子训练/验证/测试分别有 2048/512/4096 样本，使用不同随机生成器种子。相同种子下所有模型共享数据和训练批次顺序。储备池模型共享 W、B、C、控制器和读出的初始值。训练固定 100 epoch，每批 256；只按验证准确率选检查点，最后评估独立测试集。测试集未用于选 epoch 或调整超参数。

## 八种对照

| 代码名称 | 训练的组件 | 目的 |
|---|---|---|
| readout_only | 读出 | 固定随机网络、不调制 |
| controller_only | 上层＋下层 | 严格仅训练控制器；读出也随机冻结 |
| upper_only | 上层＋读出 | 下层全开，验证注入控制 |
| lower_only | 下层＋读出 | 上层全开，验证通路控制 |
| modulated | 上层＋下层＋读出 | 主实验，底层完全冻结 |
| slow_backbone | 上层＋下层＋读出＋慢速 W | 比较慢速适应 |
| rnn | 普通 RNN 全部参数 | 常规可训练时序网络 |
| mlp | 小型 MLP 全部参数 | 看完整序列的前馈基线 |

MLP 有 571 个参数，主模型训练 441 个参数；仅为接近规模的参考，不是严格等参数。RNN 有 4801 个参数，主模型还有被冻结的参数和缓冲区，不能把 441 宣传为全部模型大小。

W 使用稠密矩阵乘法和固定掩码；slow_backbone 的参数统计包括掩码外梯度为零的矩阵位置。统计的是优化器登记的参数个数，不是实际活跃边数或有效自由度。全部方法训练轮数相同但没有做充分超参数搜索，所以排名只代表本配置。

## 验证与解释约束

程序每轮实验断言冻结的 W、B、C 没有变化；严格控制器组还断言读出权重和偏置完全不变。主模型额外在测试时强制开启上层/下层，检查模型是否依赖这些门控。干预会产生分布变化，需结合重新训练的单层消融一起解读。

门控均值仅为软幅度统计，既不是比特率，也不是实际 FLOPs 节约。底层冻结仍需通过其运算反传控制器梯度，不能推断训练必然更快、更省显存。三随机种子的样本标准差不是置信区间，不应作统计显著性宣传。

本任务天然有利于“选择通道、排除晚期干扰”的归纳偏置；成功不等于可迁移到真实数据、语言推理、无限长度记忆或未知任务。

## 文件

- `experiment.py`：模型、数据、八组训练和冻结断言。
- `predict.py`：加载检查点，运行同信号不同任务指令的演示。
- `make_plot.py`：从保存指标生成科学图表。
- `REPORT.md`：实测结果与结论。
- `results/`：配置、JSON/CSV 指标、三种子训练曲线、24 个模型检查点、注入轨迹和图表。
- `verify_results.py`：重新加载24个检查点，复核测试指标及冻结参数。

## 相关工作定位

固定随机循环网络并训练读出，与储备池计算有明确联系；本实验在其上加入任务条件的注入与出边调制。不能据此宣称全新架构。

参考原论文：Reservoir Computing meets Recurrent Kernels and Structured Transforms (2020)，https://arxiv.org/abs/2006.07310 。该文支持储备池背景，不为本项目实验结果背书。
