# 第十七轮：可并行动力学可行性

## 问题

Flow-v2 的 `h_t → G_t → h_{t+1}` 反馈使串行深度为 O(T)，对未来长序列是架构级限制。本轮在**不引入新机制**的前提下，只改"接线"回答：Flow 的能力是否依赖严格的时间递归，能否转成可组合（associative scan）的形式。

## 四种接线（同架构、同参数量、同训练协议）

| 模型 | 底层非线性 | Route 输入 | 递归反馈 | 可 scan |
|---|---|---|---|---|
| A `flowv2` | tanh | [meta, pooled(h_t)] | 有 | ✗ |
| B `linear` | 无 | [meta, pooled(h_t)] | 有（线性底网） | ✗ |
| C `preroute` | 无 | [meta, x_t, 0, 0] | **无**（G_t 可预计算） | ✓ 严格 |
| D `iter` | 无 | 两遍：先预计算、再以 h⁰ 修正 | 无（两遍均为仿射扫描） | ✓ 两遍扫描 |

- 四种模型共用相同的 W/B/mask/hold/readout 与 11 维 Route 模块（C/D 的 x_t 补零到 4 维），参数量一致；RNG 对齐 v15，`flowv2` 路径应与第十五轮逐位一致。
- C 满足仿射组合：`T=(A_t, b_t)`，`T₂∘T₁=(A₂A₁, A₂b₁+b₂)`；D 的第一遍与 C 相同，第二遍以固定门做第二次仿射扫描。

## 测试

- 持续学习：A'B'C'D'、65 轮/阶段、每步 128 样本、每步旧信息带宽 16 条、r∈{0,12.5%}、3 顺序 × 5 种子。
- 20→40 步外推：每个阶段后在 40 步测试集上评估（训练仍为 20 步）。
- 5 步信用分配：所有模型训练均使用 5 步截断 BPTT（协议一致）。
- 状态轨迹漂移：`D_h = mean|h_final(t) − h_stage0(t)|`（任务 A 数据），检验"遗忘=轨迹改变"假说。
- 可并行性：`scan_check.py` 用 Hillis–Steele 前缀组合验证 C 与顺序计算数值一致，并对比 T=1024 的耗时量级。

## 判定

- 若 C ≈ A（精度/外推/CL 均接近）→ Flow 能力不依赖严格递归，可转为可组合动力学。
- 若 C 明显差、B ≈ A → 反馈闭环是核心，应转向块并行（block recurrence）。
- 若 B 明显差 → 底层非线性必要；若 B ≈ A → "非线性控制器 + 线性底网"成立。
- D 是折中：两遍扫描若接近 A，则给出"可并行 + 保留反馈"的路径。

## 边界

- 只测单一规模 N=256 与 A'B'C'D'；未扫描长度、深度与动力学参数（ρ(W)、Hold 时间常数留给下一轮）。
- C/D 的 scan 是数学性质验证，不是工程加速基准。
