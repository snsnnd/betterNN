# 第十八轮：非线性 Flow 的 block-affine 可压缩性（诊断实验）

## 背景与修正

上一稿"块 Jacobi 多遍传播"在冒烟阶段被排除：信息只在 t=0/1 注入并由状态携带，块入口每遍只能前进一个块（块 Jacobi），K<B 时末块入口恒为 0，串行深度 K·L≈T，无并行收益。

同时修正一个理论点：**在真实块入口状态处线性化再组合是恒等的**（`A_i(h̄_i)=F_i(h̄_i)=h̄_{i+1}`），因此"Oracle 线性化"本身不构成压缩损失。真正的问题是：**用廉价的近似入口状态做块线性化时，块仿射组合还能保留多少精度**。

## 设计（V18B：迭代重线性化，self-consistent relinearization）

对象：第十五轮训练好的 Flow-v2（r=12.5%、o0、5 种子、最终模型），20/40 步测试集，4 个任务。

给定块长 L（把 T 等分为 B 块）与初始入口估计 `p^(0)`：

1. 计算每块在 `p_i` 处的零阶项 `c_i = F_i(p_i)` 与 Jacobian 作用；
2. 组合传播（等价于仿射 scan）：`ĥ_0=0`，`ĥ_{i+1} = c_i + J_i(ĥ_i − p_i)`；
3. 记录 20/40 步准确率、边界状态相对误差 `E_h`；
4. 令 `p^(1)=ĥ` 重新线性化，重复 K 遍。

初始估计两种：

- `zero`：所有块入口=0（最廉价的并行起点）；
- `preroute`：用第十七轮训练好的 PreRoute 模型的状态轨迹作为入口估计（廉价可并行预测器）。

对照与诊断：

- Flow-v2（串行真值，深度 20）与 PreRoute（v17，可 scan）参考；
- 块 Jacobian 最大奇异值 `σ_max(M_i)`（幂迭代，JVP+VJP），判断误差是否被后续块放大；
- 恒等性自检：`init=oracle`（用真值入口线性化）时 `E_h` 应≈0。

## 输出

- `Effective Sequential Depth vs 40-step accuracy`（Flow / PreRoute / zero-init K=0..3 / preroute-init K=0..3，各 L∈{1,2,4,5,10}）
- `E_h vs effective depth`
- `σ_max` 诊断表

## 判定

- Oracle 自检通过 + weak-init 在 L≈4～8、K≤2 时接近 Flow（≥98% 且外推接近）→ 块仿射压缩可行，值得进入"可微 block-affine 训练"。
- 若连 K 迭代到 3 次、L=4 都明显掉 → 当前 Flow 的能力高度依赖局部闭环，停止时间并行路线，转向 B topology 与动力学区域。
- 本实验不训练任何模型、不引入新架构。

## 边界

- 线性化只在测试分布与已训练模型上评估；K 的收敛性只测 0～3 遍。
- 40 步外推下块长仍等分 T=40；σ_max 为幂迭代估计而非精确谱范数。
