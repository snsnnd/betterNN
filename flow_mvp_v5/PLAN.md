# 第五轮：反向传播窗口机制验证
依据《神经元模型比较》2026-09-25的新建议，先执行长程梯度/截断对照，再考虑持续学习、Hebbian/STDP等独立问题。本轮不将这些后续项目冒充已完成。

复用第四轮局部来源/目标模块的延迟规则任务；20步，A/B在0/1步，规则从4步起可见，最终一步监督。测试额外40步。四模型：冻结W、慢速W(0.00015)、正常W(0.003)、32单元GRU；其他参数学习率0.003。三种子，每种完整BPTT/窗口10/窗口5；共36次训练。所有组同数据、初始化、批次顺序，60轮，1024训练、512验证、2048测试。只按验证选择。

这是小规模机制筛查，不是另一对话建议的200步完整基准；预算也不同于第四轮，不直接跨轮比较。分块仅detach状态，保持数值连续；只有序列末损失，早期块没有额外局部监督。因此截断结果混合了短信用分配窗口和早期操作缺少直接监督，不能据此证明局部学习必然失败。梯度为零不等于前向状态清空。GRU和Flow未做参数或FLOPs匹配。未来可独立加入局部监督，不能在当前比较中偷偷加入。

验证：输入初两步的梯度，完整应非零、截断应零；前向detach不改变数值；保存全部检查点，重新复算两种测试准确率及冻结参数。
