# 第七轮：规模×显式节点选择（预设筛查）
N=64/128/256/512/1024，5种子11/22/33/44/55，两组dense与topk64，50条连续流、200任务训练阶段。每任务512训练256验证1024测试，30轮、batch128、Adam .003，5步截断，最后状态继续下一任务，无回放。四任务均从头训练，包括A，不复用旧检查点。本轮是固定更新预算筛查，不是充分调优后的容量上限测定；不同于v6预算，不横向直接比较数字。

任务沿用四种路由规则。为使一个序列使用固定的64节点且不因后到身份切换而清除已存值，任务身份从t0可见，两组一致；路由规则R仍到t4才出现。与v6身份到t4的协议不同。原架构四个来源/目标角色模块仍为人工给定，不能称为完全自然产生脑区。

Top-K为每个任务、每个角色学习节点分数，四块各选16，共64个允许非零状态节点。选择分数由可见任务one-hot索引，每个任务有独立分数行；这是显式的任务条件化和分区机制，不是无任务身份的自主分区。硬Top-K前向、softmax×16的straight-through代理梯度；包含任务私有参数这一额外变化，效果不能全部归于稀疏性。记录训练前选择重叠，避免把随机初始化已有的分区当成学习涌现。

dense也实例化同尺寸的未启用选择表，确保同N/seed下W/B/controller/readout初始一致。N64时两个组功能应一致。跨N数据和更新步数相同，但底层初始化不可能逐参数完全一致，控制器输入输出维度固定，读出维度增长。

Top-K稀疏状态仍用稠密PyTorch运算与代理梯度：逻辑活跃节点严格64，但不是等FLOPs或真实稀疏计算。不得声称已证明“固定实际算力”。为避免活动比例下降导致方差机械缩小，topk recurrent/head乘sqrt(N/64)，池化按活动节点数归一；该归一是本组架构组成，不可把全部差异纯归于N。

指标：每任务×阶段准确率、刚学完平均plasticity、最终平均、BWT、遗忘mean_i(max_{s>=i} A_si - A_Ti)，i仅旧任务；最终支持Jaccard与训练前Jaccard，平均绝对激活Top25%重叠、节点选择性、存在块边的gate余弦。相同原始A/B/R用于任务间诊断。低激活/低准确率时选择性不可自动解释为有用功能分区；gate余弦高不代表有效信息流完全一样。只在单顺序和合成任务验证。

分区干预与更复杂任务以后独立做，不同步改变规模与任务难度，以免混淆。未进行回放、组件冻结或梯度冲突实验，本轮聚焦用户最新的规模假设。

## 容量正对照（执行中补充，不修改主矩阵）
额外5个seed的dense64混合任务训练：与顺序实验相同四任务训练集，每任务30次遍历，总480次更新，5步BPTT；batch内单任务，batch间交替任务。每120次更新重置Adam，次数与顺序训练一致。比较同时可用旧任务数据能否让小网同时表达四种规则。这是混合任务训练上限参考，不是无回放持续学习，也不是有限K记忆基线。其结果不用于调节主实验超参数。
